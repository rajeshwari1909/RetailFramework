# Playwright TypeScript Automation Framework

A browser automation framework built with Playwright and TypeScript for the Automation Exercise application.

Application under test: [https://automationexercise.com]

## Framework goals

- Maintainable Page Object Model (POM)
- Reusable page interactions
- Test data separated from test logic
- Centralized application URL configuration
- Cross-browser execution
- HTML reporting and failure debugging

## Design

The framework follows the **Page Object Model (POM)**. Page classes contain page-specific locators and actions; test files describe the user scenarios.

```text
Test specs
    ↓
Page objects
    ↓
Playwright
    ↓
Automation Exercise
```

### LoginPage

Reusable login-related functions:

- `navigateToLogin()`
- `login()`
- `logout()`
- `verifyLoginSuccess()`
- `verifyLogoutSuccess()`

### ProductPage

Reusable product-related functions:

## Test data and configuration

User credentials are maintained separately in [`testdata/user.ts`](testdata/user.ts), keeping test data separate from test logic.

The application URL is configured as Playwright's `baseURL` in `playwright.config.ts`:

```typescript
baseURL: 'https://automationexercise.com'
```

Tests can navigate using a relative path:

```typescript
await page.goto('/');
```

## Prerequisites

- Node.js
- npm

## Setup

Install the project dependencies and Playwright browsers:

```bash
npm install
npx playwright install
```

## Run tests

Run all tests:

```bash
npx playwright test
```

Run a specific test:

```bash
npx playwright test tests/login-user.spec.ts
```

Run tests in a specific browser:

```bash
npx playwright test --project=chromium
npx playwright test --project=firefox
npx playwright test --project=webkit
```

## Reporting and debugging

- HTML reports are generated by Playwright.
- Screenshots are captured when a test fails.
- Traces are collected on the first retry and can be opened in Trace Viewer.
- Playwright debugging tools can be used to investigate test failures.

Open the HTML report after running tests:

```bash
npx playwright show-report
```
